Lume Client

A fast Minecraft: Java Edition client written in Rust.

What it is

Lume Client is a Minecraft: Java Edition client built in Rust on top of the open-source Horizon engine (MIT). It focuses on performance and on quality-of-life features for players: a customizable HUD, an in-game mod menu, free look, configurable screen scaling and accessibility options.

Accounts and ownership

  • Players sign in with their own Microsoft account using the official Microsoft device-code flow.
  • The client only plays with accounts that own Minecraft: Java Edition, and joins online-mode servers like the official game.
  • It ships none of Minecraft's code, textures or sounds: they are prepared from the player's own copy of the game.
  • Tokens are stored only on the player's computer, in the operating system's credential store, and are sent only to Microsoft, Xbox Live and Minecraft services.
